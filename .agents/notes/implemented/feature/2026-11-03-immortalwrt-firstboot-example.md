# Agent Note: ImmortalWrt 首次启动示例的配置边界

Status: implemented

## Problem

用户在发版前提供个人首次启动脚本，希望将可用部分纳入 ImmortalWrt 示例。原模板缺少配置对象与错误检查；提供的脚本重复提交 LuCI、无条件移除旧 netmask，并以 exit 0 掩盖请求失败。其 Cooluc 段固定 APK 25.12 源且公钥/摘要已脱敏，用户进一步询问页面已有软件源功能是否可以替代它。

## Decision

`www/uci-defaults/immortalwrt.sh` 是可编辑的基础示例。所有赋值默认注释，不改变未选择的配置；用户可以显式配置 root 密码、IPv4/CIDR LAN、第一组无线接口、PPPoE、LuCI 语言、已安装 Argon 和系统时区。配套 `immortalwrt.zh-cn.sh` 仅翻译注释，执行代码、日志和示例赋值保持一致；简中与繁中界面共用中文注释，其他语言插入英文，具体选择、去重与竞态由[分系统草稿](2026-10-30-uci-defaults-drafts.md)管理。配对中英文使用文档解释变量和风险，按系统隔离与分享契约不变。

脚本块在子 shell 中运行，日志重定向、辅助函数和 exit 不污染拼接后的其他命令。日志设置 0600、状态消息不带凭证，涉及密码的命令输出被抑制。可选组件不存在时跳过；请求的配置不完整、对象不存在或写入/提交失败时返回非零，不能报全部成功。若用户继续追加命令，整个脚本最终退出码仍由其组合方式决定。

LuCI 语言与主题只提交一次，Argon 只在静态资源目录存在时设置，不安装软件或重启服务。时区名称和 POSIX 时区成对填写。LAN 验证 IPv4 与可选前缀，仅 CIDR 输入移除存在的旧 netmask；旧版本裸地址保留原掩码，25.12 之后文档要求 CIDR。无线凭据成对提供并限制长度，缺少硬件的设备保持未配置即可。

通用示例不预置 Cooluc 源或公钥，避免把个人指定版本配置变成所有系统的默认行为。页面自定义源用于构建；已检查的 ASU 把公钥及源注入 ImageBuilder 目录，不代表最终设备保留这些文件。首次启动时写入设备源则用于后续安装，不能解决构建阶段后端不接受源的问题。当前 OpenWrt 官方允许列表为空，所核对的 ASU 源码空名单不放行；两个 ImmortalWrt 后端本次查询 403，不能宣称已验证 Cooluc 可用。

## Related notes

按 uci-defaults、模板、软件源检索活跃笔记：[分系统草稿](2026-10-30-uci-defaults-drafts.md)保留前端状态契约并互链，本篇接管 ImmortalWrt 示例的执行行为；[高级构建选项](2026-10-30-asu-build-options.md)保留构建请求字段契约，本篇说明其与设备运行时源的区别。没有需要归档或删除的提案。

## Alternatives considered

- 直接复制用户完整脚本：个人机器所需内容齐全，但固定 LAN、默认中文/时区、特定 APK 源和占位公钥不能直接作为多版本通用默认值；改为显式启用的基础配置。
- 完全依赖页面的软件源字段：可避免两处维护，但 ASU 构建源与设备运行时源不同，后端还有允许列表，不能承诺页面输入会留在固件中。
- 按固件版本自动猜测网络和源格式：能减少填写步骤，但快照、自建版本和厂商配置无法由简单版本比较准确判断；保留显式地址格式与独立部署配置。

## Verification

新增 9 组 Python/unittest 回归用真实 POSIX shell 解释脚本，模拟 uci、passwd、logger 和 sync，日志/主题目录重定向到自动清理的临时目录，不修改主机或路由器。覆盖默认无写入、语言主题合并提交、缺组件、时区成对、旧掩码/CIDR、非法地址、凭证不入日志、缺接口与失败非零。Windows 使用 Git for Windows 的 sh，并只为该子进程补充工具路径。9 组通过，sh -n 及 8 项草稿状态测试通过。

API 检查仅 GET 元数据，源码依据固定为 ASU 77c5636045b0aed0762727363be105b2a5fa47fd；未提交真实固件构建、安装第三方包或进行开机实机验收。模拟通过不能证明任意设备/版本的主题、无线或软件源兼容性。

浏览器读取两份真实本地模板，通过 ImmortalWrt 示例追加/去重、同系统两个后端草稿保留、跨系统隔离及恢复，pageerror 为 0，没有构建 POST。浏览器、本地服务器和本次临时控制台日志已清理；唯一资源错误来自被测试路由拦截的浏览器外部注入脚本。14 份双语文档的 69 个相对链接/锚点与成对代码块通过，11 篇笔记三项门禁通过。

## Consequences

示例适合用户按需启用，避免静默改变网络或导入不可用源；失败可以被 uci-defaults 调用方识别，日志不泄露凭证。代价是仍需用户填写真实设备参数，并在具体固件上验收。对只读镜像与 overlay，脚本原件和内嵌凭证仍留在固件里，恢复出厂设置可能重跑；改进日志不能消除这一固件行为。
