Wrt Selector `site-v1.1.0` 帮助 OpenWrt 和 ImmortalWrt 用户判断两件事：该下载哪个映像，以及把 `uci-defaults` 示例加入固件后，设备首次启动时会改哪些设置。这是选择器网站的版本，不是路由器固件版本。

[在线使用](https://addgm.github.io/wrt-selector/) · [使用指南](../zh-CN/usage.md)

## 本版本重点

- **区分整盘映像和根文件系统。** 在 x86 上，传统 BIOS 启动选 `COMBINED`，UEFI 启动选 `COMBINED-EFI`。独立 `ROOTFS` 不能单独启动；已有配套内核、需要单独部署根分区时才选它。列表能确认格式时，还会说明 ext4 可直接读写，而 SquashFS 的基础系统只读，配置更改通常保存在可写叠加层。
- **区分首次安装、升级和恢复。** Factory 和 Sysupgrade 的说明现在分别解释从原厂固件安装和升级现有兼容系统的场景。用于恢复的 `initramfs` 可从内存临时启动，启动它不等于把系统装入闪存。`zImage`、`uImage` 能正确显示内核说明；Broadcom BCM63xx 的 CFE 映像会提示核对闪存容量或地区后缀。无法识别的文件不会被推荐为通用 LuCI 升级包。
- **首次启动示例的注释、日志和错误提示使用同一种语言。** 点击“插入当前系统示例”时，简体中文和繁体中文界面共用所选发行版的中文脚本，其他所有界面语言默认使用该发行版的英文脚本。切换语言不会改写已有草稿。界面语言菜单还新增了上游的阿塞拜疆语选项。

## 运行环境

使用启用 JavaScript 的现代浏览器，并确保能访问所选发行版的下载目录；定制固件还需能访问所选的在线构建服务。自建站点只需要静态 HTTP(S) 托管，不需要 Node.js 或固件编译环境。

## 使用与部署

1. **下载前核对机型和硬件版本。** 实体磁盘与虚拟磁盘的用法不同：将原始 `.img` 写入实体盘会覆盖原有分区；虚拟磁盘文件应挂载到虚拟机。具体安装方法以该机型的指南为准。
2. **定制构建前检查脚本。** 编辑器初始为空。若将内置示例加入固件并保持原样，首次启动时会在相应配置存在时将 LuCI 设为简体中文、将系统时区设为 `Asia/Shanghai`；仅在已安装 Argon 时切换主题，不安装语言包或主题。**英文脚本也会应用相同设置。** 如需保留设备原有语言或时区，请在请求构建前移除对应设置段。root 密码、Wi-Fi、PPPoE 和 LAN 地址默认不改；`192.168.10.1` 和 `192.168.10.1/24` 都只是注释中的示例。
3. **从 `site-v1.0.1` 升级自建站点无需迁移配置格式。** 先备份自定义的 `config.js` 和首次启动模板；核对站点 ZIP 的 SHA-256 后，将内容解压到 Web 根目录，再合并自己的修改并刷新静态资源缓存。升级网站不会更改已部署的设备。详见[配置指南](../zh-CN/configuration.md)和[部署指南](../zh-CN/deployment.md)。

## 已知限制

- 映像说明不能验证设备兼容性。缺少专用译文时，列表显示当前语言的通用说明；连通用说明也没有时，只显示映像类型名。自动化检查不代替实机刷写或首次启动验证。
- 写入首次启动脚本的 root 密码、Wi-Fi 密钥和 PPPoE 凭据会随请求发给在线构建服务，也会留在固件中。建议首次登录后再通过 LuCI 设置这些凭据，不要分发含有个人凭据的固件。
